# Corso di Word

**Destinatari:** ragazzi di 13 anni · **Software:** Microsoft Word (365, interfaccia in italiano)

Cinque esercizi progressivi. In ogni documento **la prima pagina è il risultato** da rifare
e **le pagine successive spiegano come farlo**, passo per passo, con una lista di controllo
finale e una sfida facoltativa per chi finisce prima.
